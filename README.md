## 🚀 Proyecto destacado

### [AudienceMD](https://audiencemd.ai/) · [`AUDIENCE.md`](https://github.com/KikoPalomares/audience.md)

Un estándar abierto en Markdown para definir **para quién es un producto, contenido, campaña o proyecto**.

La idea es simple: que humanos y agentes de IA compartan una fuente de verdad clara, versionable y útil sobre la audiencia antes de escribir copy, diseñar flujos, priorizar features o tomar decisiones de producto.

- Web: [audiencemd.ai](https://audiencemd.ai/)
- Repo: [`KikoPalomares/audience.md`](https://github.com/KikoPalomares/audience.md)
- CLI: [`@audiencemd/cli`](https://www.npmjs.com/package/@audiencemd/cli)
