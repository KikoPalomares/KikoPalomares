## 🚀 Featured project

### [AudienceMD](https://audiencemd.ai/) · [`AUDIENCE.md`](https://github.com/KikoPalomares/audience.md)

**AudienceMD** is an open Markdown-based standard for defining **who a product, piece of content, campaign, or project is for**.

The goal is simple: give humans and AI agents a clear, versionable source of truth about the audience before writing copy, designing flows, prioritizing features, or making product decisions.

- Website: [audiencemd.ai](https://audiencemd.ai/)
- Repository: [`KikoPalomares/audience.md`](https://github.com/KikoPalomares/audience.md)
- CLI: [`@audiencemd/cli`](https://www.npmjs.com/package/@audiencemd/cli)
